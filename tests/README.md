# Тестирование проекта

В этом каталоге находятся автоматические тесты для консольного приложения учёта инвентаря.

## Инструменты
* **Фреймворк:** `pytest`
* **Конфигурация:** зависимости зафиксированы в `requirements.txt`

## Структура каталога
* `test_inventory.py` — набор модульных тестов для модели `Equipment`, справочника `Inventory` и демонстрационных данных `demo_inventory()`.

## Запуск тестов

Для запуска всего набора тестов выполните из корневой директории проекта команду:

```bash
python -m pytest
