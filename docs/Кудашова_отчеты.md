# Отчёт о тестировании — Спринт 3

**Роль:** QA / DevOps  
**Дата:** День 3

## Цель проверки
Проверить реализацию поиска, изменения и удаления записей инвентаря.

## Что проверялось

### 1. Поиск по инвентарному номеру
- [ ] Поиск существующего номера — показывается карточка
- [ ] Поиск несуществующего номера — сообщение «Не найдено»
- [ ] Пустой ввод — программа не падает

### 2. Изменение записи
- [ ] Можно изменить кабинет
- [ ] Можно изменить состояние
- [ ] После изменения данные корректно отображаются в списке
- [ ] Попытка изменить несуществующую запись — понятная ошибка

### 3. Удаление записи
- [ ] Перед удалением запрашивается подтверждение
- [ ] При подтверждении запись удаляется
- [ ] При отмене запись остаётся
- [ ] Попытка удалить несуществующую запись — корректная обработка

### 4. Регрессия
- [ ] Пункт «Показать оборудование» продолжает работать
- [ ] Добавление записей (из Спринта 2) не сломалось
- [ ] Программа не завершается аварийно при ошибках ввода

### Передача роли QA / DevOps

**Что нужно сделать в Спринте 4 (QA):**
- Проверить сохранение данных между запусками программы
- Проверить поведение при отсутствии файла данных
- Проверить поведение при пустом файле
- Проверить поведение при повреждённом (испорченном) JSON
- Проверить повторный запуск после ошибок
- При наличии Docker — создать простой Dockerfile и проверить сборку

| Обычный запуск             | Данные загружаются автоматически                 |
| После изменений            | Данные сохраняются на диск                       |
