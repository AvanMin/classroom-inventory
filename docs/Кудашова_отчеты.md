## Согласованные правила

### Формат хранения
- Файл: `data/inventory.json`
- Структура записи: inventory_number, type, name, room, state, received_at, responsible

### Поведение программы
| Ситуация                    | Ожидаемое поведение                              |
|----------------------------|--------------------------------------------------|
| Файл отсутствует           | Создаётся новый файл, программа запускается      |
| Файл пустой                | Программа запускается, список пуст               |
| Файл повреждён (битый JSON)| Понятное сообщение об ошибке, без тихой потери данных |
| Обычный запуск             | Данные загружаются автоматически                 |
| После изменений            | Данные сохраняются на диск                       |
