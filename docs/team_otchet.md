# Сводный отчёт команды по итогам трёх спринтов

**Проект:** Система учёта инвентаря компьютерных классов  
**Участники:** Кудашова М., Кочедыков Т., Лаврова М.  
**Период:** Спринты 1–3 (дни 1–3)  
**Цель проекта:** разработать консольное приложение на Python для учёта компьютерного оборудования с использованием Git, тестирования и базовой документации.

**Роли:** PO — Кудашова, LD — Кочедыков, QA / DevOps — Лаврова.

## Спринт 3. Поиск, редактирование, удаление
**Роли:** PO — Кочедыков, LD — Лаврова, QA / DevOps — Кудашова.

### Что сделано

- **Lead Developer:** реализованы методы `search_by_room()`, `update()` (через `dataclasses.replace` с сохранением неизменяемости модели), `delete()`; привязаны пункты меню 3–5; добавлена функция `print_equipment_card()` для вывода карточки и подтверждение удаления `y/n`.

### Достигнутые результаты

- **Функциональность:** реализованы просмотр, добавление, поиск, изменение и удаление записей; все операции работают через консольное меню.

- Нет тестов на файловый ввод-вывод (появятся после реализации `storage.py`).
