# classroom-inventory
# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в учебных кабинетах.

## Цель проекта

Разработать работающее консольное приложение, которое позволяет:
- просматривать список оборудования;
- добавлять новые записи;
- искать оборудование;
- изменять данные;
- удалять записи;
- сохранять данные в JSON-файл.

## Пользовательские сценарии

### 1. Первый запуск
1. Запустите программу: `python main.py`
2. Если файла `data/inventory.json` ещё нет — программа создаст его автоматически.
3. Можно сразу добавлять записи.

### 2. Обычная работа с сохранением
1. Добавьте, измените или удалите записи.
2. Закройте программу.
3. Запустите снова — все изменения должны остаться.

### 3. Файл данных отсутствует
1. Удалите файл `data/inventory.json`.
2. Запустите программу.
3. Программа не должна падать. Будет создан новый файл.

### 4. Повреждённый файл данных
1. Откройте `data/inventory.json` и испортите его (удалите скобку, напишите текст и т.д.).
2. Запустите программу.
3. Программа должна показать понятное сообщение об ошибке и не потерять данные молча.
