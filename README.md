# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в учебных кабинетах.

## Цель проекта

Разработать работающее консольное приложение, которое позволяет:
- просматривать список оборудования;
- добавлять новые записи;
- искать оборудование;
- изменять данные;
- удалять записи;
- сохранять данные в JSON-файл.

## Пользовательские сценарии

### 1. Первый запуск
1. Запустите программу: `python main.py`
2. Если файла `data/inventory.json` ещё нет — программа создаст его автоматически.
3. Можно сразу добавлять записи.

### 2. Обычная работа с сохранением
1. Добавьте, измените или удалите записи.
2. Закройте программу.
3. Запустите снова — все изменения должны остаться.

### 3. Файл данных отсутствует
1. Удалите файл `data/inventory.json`.
2. Запустите программу.
3. Программа не должна падать. Будет создан новый файл.

### 4. Повреждённый файл данных
1. Откройте `data/inventory.json` и испортите его (удалите скобку, напишите текст и т.д.).
2. Запустите программу.
3. Программа должна показать понятное сообщение об ошибке и не потерять данные молча.

## Запуск и использование

**Требования:**
* Python 3.11 или новее.
* Установленные зависимости из `requirements.txt`.

**Инструкция по локальному запуску:**
1. Склонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение (venv).
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите программу командой: `python main.py`.

*(Опционально: для запуска через Docker выполните `docker build -t inventory .` и `docker run -it inventory`).*

**Команды консольного меню:**
При запуске открывается текстовое CLI-меню.
* `1` — Показать всё оборудование в базе.
* `2` — Добавить новую запись (система запросит инвентарный номер, тип, название, кабинет и состояние).
* `3` — Найти оборудование по инвентарному номеру.
* `4` — Изменить кабинет или состояние у существующей карточки.
* `5` — Удалить запись (требует подтверждения действия `Y/N`).
* `0` — Выйти из программы с безопасным сохранением данных.

**Известные ограничения системы:**
* Приложение работает исключительно в текстовом терминале, графический интерфейс отсутствует.
* База данных хранится локально в файле `data/inventory.json`. При удалении этого файла все данные будут безвозвратно утеряны.
* Многопользовательский режим не поддерживается (нет защиты от одновременного редактирования файла с разных устройств).
